DEPLOYMENT ARCHITECTURE NOTE (read first — honest description of method)
--------------------------------------------------------------------------------
This project is deployed to a Hostinger KVM2 VPS running Docker Compose, NOT to
Hostinger shared hosting via rsync-to-public_html. The tag-triggered GitHub
Actions workflow deploys through a SELF-HOSTED GitHub Actions runner installed
on the VPS itself (systemd service, label "taxnexus-vps").

Why self-hosted runner instead of SSH/rsync from a GitHub-hosted runner:
the Hostinger cloud firewall permits only 80/443 + admin IPs inbound, so a
GitHub-hosted runner cannot open SSH/SFTP to the VPS (dial tcp :22 i/o timeout).
The self-hosted runner connects OUTBOUND to GitHub and deploys locally, so the
firewall stays closed. The deploy job checks out the tagged commit, rebuilds the
Docker image, recreates the app container (the "build artifact"), and gates on a
live /health 200. This satisfies "build + deploy the artifact on a tagged
release" using an automated method the Hostinger plan supports.

SECTION 3 — BACKUPS
================================================================================
Method              : Scheduled script on the Hostinger VPS via cron.
                      scripts/backup.sh (committed to the repo, NO secrets)
                      runs `mysqldump --all-databases` inside the db container
                      via `docker exec` and writes a gzip archive. The MySQL root
                      password is read INSIDE the container from its own
                      MYSQL_ROOT_PASSWORD env (exported to MYSQL_PWD) — it never
                      appears in the script, host process list, or shell history.
Schedule            : Nightly at 02:00 (server time) — cron entry:
                      0 2 * * * /root/soloai_starter/scripts/backup.sh >> /var/log/taxnexus-backup.log 2>&1
Filename pattern    : taxnexus-YYYYMMDD-HHMM.sql.gz   (sortable, timestamped)
Retention           : >= 7 days. RETENTION_DAYS defaults to 7; the script prunes
                      with: find "$BACKUP_DIR" -name 'taxnexus-*.sql.gz' -type f
                      -mtime +7 -print -delete
