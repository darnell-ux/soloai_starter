You are a staff-level reviewer. Perform a **course-sequence submission review**
of this SvelteKit + TypeScript repository against the five criteria below.

### Global rules
1. Use tools to **read source files** under `src/`, `docs/`, `.claude/agents/`,
   config roots (`vite.config.ts`, `tailwind.config.js`, `playwright.config.ts`,
   `package.json`, CI under `.github/` if present).
2. Prefer **terminal verification** for automated tests when possible:
   - `npm run test:unit -- --run`   (Vitest)
   - `npm run test:e2e`            (Playwright; may take longer)
   If you cannot run commands, say so explicitly and rely on reading test
   files plus `playwright.config.ts` / Vitest configs — but **running tests
   is strongly preferred** for criterion 2.
3. Every criterion section must include:
   - **Verdict:** Meets rubric / Partially meets / Does not meet (with reason)
   - **Evidence:** bullet list of file paths (and brief notes)
   - **Gaps / risks:** what remains for production hardening (if any)

### Criterion 1 — Refactoring report (LLM-generated: resolved issues + improvements)

`docs/code-review-billing-analytics-criteria.txt`.
